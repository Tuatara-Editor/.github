## Tuatara

A text editor for the terminal and the desktop, written in Common Lisp:
Org files, code coloured by tree-sitter with language servers, CSV files of
many gigabytes, mail folders and folders of files, with modal keys or plain
ones. Made to open files from anywhere safely: nothing in a file is ever run.

- [tuatara](https://github.com/Tuatara-Editor/tuatara): the editor
- [tuatara-packages](https://github.com/Tuatara-Editor/tuatara-packages):
  packages loaded on asking, each for one job not everyone needs

Contributions come through pull requests from approved contributors; see
each repository's `CONTRIBUTING.md`.
